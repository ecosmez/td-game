# CC Traps (Slow / Root / Freeze) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 6 store-buyable crowd-control traps (Slow/Root/Freeze × Field(pulse)/Snare(one-shot)) that apply status effects to enemies via the existing `BP_Enemy` Stun infrastructure, extended with matching Slow/Root timers.

**Architecture:** Two small C++ changes (Root gating in the enemy-path library, 6 new Tower Store catalog entries) plus Blueprint work done live in the running editor through the Unreal MCP `BlueprintTools`/`ActorTools` toolset: new timer/decay logic on `BP_Enemy`, one new shared `BP_Trap_Base` actor (radius-based detection, mirroring the existing Mine tower's proven AoE pattern instead of a physical collision volume), 6 new `BP_BuildManager` Select functions, and 6 new dispatch branches in `BP_BuildManager`'s `SpawnAndStartTower`.

**Tech Stack:** Unreal Engine 5.8, C++ (UBT), Blueprint (edited via `unreal-mcp` MCP server against the live editor).

**Spec:** `docs/superpowers/specs/2026-08-20-cc-traps-design.md`
