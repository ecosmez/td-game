; Moba RTS/MOBA free-camera system (C++ TD module)
;
; Classes:
;   AMobaCameraPawn        - independent SpringArm camera (edge/WASD/MMB/zoom/Space focus)
;   AMobaPlayerController  - GameAndUI input mode, ControlledChampion, GetControlledChampion
;   AMobaGameMode          - defaults PlayerController + DefaultPawn to free camera
;
; ALWAYS use AMobaPlayerController on gameplay maps (not BP_TopDownController).
; BP_TopDownGameMode / Level0 / Lvl_TopDown use:
;   Player Controller Class = AMobaPlayerController
;   Default Pawn Class      = BP_TopDownCharacter (controller re-possesses free camera at BeginPlay)
;   Optional free-cam path: Default Pawn = AMobaCameraPawn + ChampionClass on controller
; Character sky drop: SetDropMode(true/false) on AMobaPlayerController (not BP_TopDownController)
; Run Content/Python/set_moba_player_controller.py after template merges to re-assert settings.
;
; Enhanced Input assets (optional - runtime defaults exist if missing):
;   /Game/TD/Input/MobaCamera/IA_CameraMove
;   /Game/TD/Input/MobaCamera/IA_CameraZoom
;   /Game/TD/Input/MobaCamera/IA_CameraRotate
;   /Game/TD/Input/MobaCamera/IA_CameraDrag
;   /Game/TD/Input/MobaCamera/IA_CameraFocusChampion
;   /Game/TD/Input/MobaCamera/IMC_MobaCamera
; Run Content/Python/create_moba_camera_input.py in the editor to generate them.
;
; Controls (after land / grounded):
;   Edge of screen - edge scroll (unlocks from champion lock)
;   Mouse wheel    - zoom
;   MMB drag       - pan (cancels champion lock)
;   Space          - sticky lock + center on champion
;   WASD / QE      - disabled for free-cam when grounded (bEnableKeyboardCameraMoveWhenGrounded)
;
; Camera follow: bLockedToChampion starts true so freefall steer + post-land walk keep framing.
; Drop force-follow: bFollowWhileChampionDropping snaps XY while bIsDropping even if player panned.
;
; Existing BP_TopDownCharacter LoLCameraComponent is champion-attached edge pan.
; This free-camera pawn REPLACES that architecture when MobaGameMode is used.
; Disable LoLCamera on the champion (or remove component) to avoid double cameras.
