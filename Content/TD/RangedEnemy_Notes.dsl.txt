; Ranged enemies for waves — shipped summary
; Design: mix targets (crystal/towers/champion); stop-and-fire; mix from wave 2
;
; Assets:
;   /Game/TD/BP_RangedEnemy       child of BP_Enemy (bIsRanged=true)
;   /Game/TD/BP_EnemyProjectile   hits Crystal / Tower / Champion
;
; Behavior:
;   BP_RangedEnemy EventTick -> TryRangedOrAdvance
;   In range: stop, face nearest target, FireRangedShot on AttackInterval
;   Out of range / wall / crystal-melee / stunned: AdvanceAlongPath
;     (C++ Catmull-Rom along BP_Waypoint; no BP_EnemyPath)
;
; Spawn mix (SpawnEnemyInner / SpawnNextWaveEnemy):
;   Each chosen spawn gets 12 + WaveNumber * 8 minions (+1 on boss waves).
;   Wave 1 uses only the primary route; later waves keep it and add others.
;   Wave N uses up to N distinct spawns (wave 3 can use all 3 routes).
;   Example: wave 2 with 2 routes -> 28 from spawn 0, 28 from spawn 1.
;   Only the primary spawner (lowest RouteId) runs the wave; others are
;   spawn-point markers so the player must cover more than one approach.
;   Spawn interval starts at 0.55s and drops 0.05s per wave (floor 0.30s).
;   Boss wave (IsBossWave, or WaveNumber % BossWaveNumber == 0): first spawn
;   is BP_Boss, then trash / ranged.
;   Wave >= RangedStartWave (default 2)
;   Every 3rd non-boss spawn (WaveSpawnedCount % 3 == 0) -> BP_RangedEnemy
;
; New damage receivers:
;   BP_Tower.ApplyTowerDamage (MaxHealth 80)
;   BP_TopDownCharacter.ApplyChampionDamage (MaxHealth 150)
;
; Tunables on BP_RangedEnemy CDO:
;   AttackRange 750, ProjectileDamage 8, MoveSpeed 200, MaxHealth 20, AttackInterval 1.5
